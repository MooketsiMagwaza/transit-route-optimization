# Brand direction: from TransitOS to Tsela

## Working recommendation

Use **Tsela** as the public working name and keep **TransitOS** only as the internal platform/repository name. “Tsela” means path, road, way, manner, or method in Setswana sources, and feels closer to a helpful local guide than an operating system.

This is a creative direction, not legal clearance. Before renaming packages, domains, social handles, or API prefixes, complete Botswana and regional trademark searches, domain availability checks, pronunciation testing, and interviews with Setswana-speaking riders.

## Name shortlist

1. **Tsela** — concise, route-centered, locally grounded. Current lead.
2. **Tsamaya** — active and friendly (“go” / “travel”), but longer and more likely to be used in existing names.
3. **Kombi Map BW** — immediately descriptive, but harder to protect and less expandable.

## Visual system

Superseded by [`docs/DESIGN_PRINCIPLES.md`](DESIGN_PRINCIPLES.md), which is now the source of truth for how the four surfaces look; this section only records how the direction changed.

The system went through two revisions before settling. First a warm cream canvas with acid lime accents and neo-brutalist hard shadows; then a hand-inked, clay-accented look; both read as decoration rather than product. The current direction follows the structure and tone of the [Android Developers](https://developer.android.com/studio) site: a white and light-grey canvas, near-black ink, one blue (`#0b57d0`) for actions and links, Tsela green (`#146c2e`) reserved for the brand mark and "field verified", thin 1px borders instead of shadows, pill buttons, and modest corner radii. Every page picks its own hero for what it's about rather than reusing one template — see `DESIGN_PRINCIPLES.md` for the checklist this is held to, and the real screenshots in the README's product gallery for how it actually looks, in both light and dark.

Route lines and stops remain the core graphic language on the map; the rider app follows Material navigation conventions (a rail on desktop, a bottom bar with a pill indicator on phones) because most riders are likely on Android. A small set of hand-inked illustrations, generated by a seeded deterministic program rather than drawn by a person or an image model, appears sparingly — once per marketing page at most.

## Draft assets

- `design/tokens.css` — the single source for colour, type, radius, shadow, spacing, and motion, copied into each app by `node design/sync.mjs` (`--check` fails when a copy drifts).
- `design/tsela-icon.tsx` and `design/tsela-art.tsx` — the shared icon set and the generated illustration scenes, copied the same way.
- `design/theme-toggle.tsx` — the light/dark toggle shared by marketing, rider, and admin (the developer portal uses Fumadocs' own).
- `marketing/public/brand/tsela-mark.svg` and `marketing/app/icon.svg` — the route-loop mark, now dark green (`#146c2e`) rather than black-and-white-and-lime.
- `marketing/components/brand-mark.tsx` — the reusable inline wordmark used by the site.
- `marketing/app/brand/page.tsx` — the public identity, colour, and illustration reference; its swatches are the current, accurate hex values.
- `marketing/app/opengraph-image.tsx` — the share-card asset.
